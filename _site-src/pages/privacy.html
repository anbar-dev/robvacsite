A SMALL, STATIC SITE

Privacy should be easy to understand.

You do not need a DustMigo account to browse or use the finder. Google Analytics measures visits to this site; finder answers are processed in your browser and are not sent to DustMigo or included in Analytics events. Reporting a correction through GitHub is optional and requires a GitHub account.

What this site does

The robot-vacuum finder runs in your browser. Your selections are used to show a recommendation, then discarded when you leave or refresh the page. No profile is created and the answers are not sent to DustMigo.

This site loads Google Analytics on every page for basic site-use measurement. It does not use advertising pixels or third-party fonts; text uses fonts already available on your device.

Google Analytics

DustMigo uses Google Analytics 4 with measurement ID {{analyticsId}} to measure page visits and understand how the site is used. The Google tag loads from Google and sends standard measurement information such as the page URL, referrer, browser and device details, and an online identifier. When an affiliate link is clicked, DustMigo also sends an affiliate_click event with the clicked model, part category, Amazon product identifier (ASIN), and link position. Depending on the Google Analytics property settings, additional interaction events may be collected. The finder’s selected answers are not read or sent as Analytics event values by DustMigo.

Google may use cookies or similar identifiers for measurement and handles data under its Privacy Policy. See also Google Analytics data collection documentation.

Amazon images and links

Product photographs load directly from Amazon image servers. Your browser contacts those servers to retrieve the files, which exposes ordinary request information such as your IP address and browser details to Amazon. Your finder answers are not included in those image requests.

If you choose an Amazon link, you leave DustMigo and Amazon’s privacy practices apply. Amazon may set cookies or use other technologies on its own site. Review Amazon’s privacy notice and settings for details.

Hosting logs

When this static site is hosted, the hosting provider may process basic server logs such as IP address, requested file, browser information, and request time for security and operations. Check the current GitHub Pages privacy documentation and applicable terms once the site is deployed.

Corrections and changes

For corrections, this site links to GitHub Issues; it does not embed an issue form or send your finder answers. Submitting a report requires a GitHub account. Information submitted there is handled by GitHub under its privacy statement. Current as of October 6, 2026.
