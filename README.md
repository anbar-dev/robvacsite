# DustMigo

A small, static robot-vacuum buying guide built with HTML, CSS, and vanilla JavaScript for GitHub Pages.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server. No build step or backend is required.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`.
3. Keep the root `CNAME` file in the published branch and add `dustmigo.com` in GitHub Pages custom domain settings if it is not detected automatically.
4. At the domain registrar, point the apex domain to GitHub Pages using GitHub's current DNS instructions, and add `www` as a CNAME to the Pages host if you want it to resolve too.
5. Wait for DNS and HTTPS provisioning, then check both the apex domain and any `www` redirect.

GitHub Pages uses Jekyll by default. These files are plain HTML and assets; the Pages build can publish the repository root directly. If you later add folders beginning with `_`, add an empty `.nojekyll` file at the root.

## Before launch

- Confirm `robvac93-20` is the active Associates tracking ID for the US store and test every tagged Amazon destination.
- Review the Amazon Associates and local advertising/privacy requirements for the markets you plan to target.
- Recheck each product variant, manufacturer specs, Amazon availability, and all page dates.
- Connect a Search Console property after the domain is live. No analytics are included by default; add a privacy-friendly provider only if you have a clear measurement question and update `privacy.html` first.
- Configure an email/contact path before inviting reader corrections.

No framework, package install, build command, runtime API, or backend is needed.
